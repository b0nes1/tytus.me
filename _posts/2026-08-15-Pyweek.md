# Python Community Event Branding

I'm a member of the events team at [Python Discord](https://pydis.org), an online community of over 300,000 members, where I help to organize community events and design the banners and icons used to promote them.

One of our partner organizations is [PyWeek](https://pyweek.org/), which runs a biannual programming competition in which participants build a game in Python within a single week. The event aims to give amateur programmers the confidence to code, work collaboratively, and gain experience with Git version control.
