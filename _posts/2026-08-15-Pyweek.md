# Python Community Event Branding

I'm a member of the events team at [Python Discord](https://pydis.org), an online community of over 300,000 members, where I help to organize community events and design the banners and icons used to promote them. The graphics displayed below are created by me in Adobe Illustrator and Photoshop.

One of our partner organizations is [PyWeek](https://pyweek.org/), which runs a biannual programming competition in which participants build a game in Python within a single week. The event aims to give amateur programmers the confidence to create larger projects, work collaboratively, and gain experience with Git version control.

Aside from PyWeek, we host our own annual game jam, where members are randomly placed into teams of six and given 11 days to create a Python project using a specified technology and theme.

![image](/assets/Summer Code Jam.jpeg)


This year, we are reviving the “Pixels” event, where participants collaboratively draw on a shared pixel canvas, providing an introduction to working with APIs.
